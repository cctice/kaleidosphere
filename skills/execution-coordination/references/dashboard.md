# 执行仪表盘

在 KS 参与的任务实际发生文件修改、Git 操作或工作现场状态变更后，输出以下固定顺序的简短仪表盘。它是给用户扫描的投影；`Execution State` 是唯一状态真源。

1. `工作目标`：当前范围的目标。
2. `当前现场`：单会话明确“无协同”，协同时概述当前协同现场。
3. `最高 blocker`：最高优先级阻塞或人工 gate；无则写“无”。
4. `已完成`：已完成的当前范围步骤。
5. `当前`：正在执行的唯一步骤。
6. `唯一下一步`：完成当前步骤后的唯一下一动作。
7. `行动`：最多三项当前行动；无则写“无”。
8. `待办`：最多三项非即时待办；无则写“无”。

仅复杂开发、验证或发布任务额外展示以下字段：

- `实现覆盖`：当前范围已实现部分。
- `独立 DoD 验证覆盖`：由独立 verifier 复验的部分。
- `发布就绪度`：当前范围距离发布条件的状态。

每项值只用一行短语。路径、长证据、完整日志和完整待办通过可审计查询获取，不进入仪表盘。不得把绿色或“完成”表述为整个项目、批次或发布已经交付，除非对应范围的退出条件已被独立证据满足。

状态颜色含义固定：灰色表示未启动或不适用，黄色表示执行中或等待 gate，红色表示阻塞、失败或越权待处置，绿色表示当前范围的退出条件已满足。颜色只描述当前字段的状态，不能替代证据或扩大完成范围。
