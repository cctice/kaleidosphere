# KaleidoSphere (万花境)

KaleidoSphere is a plugin-based AI work resource coordination layer for
human-agent collaboration. This plugin provides the KS entry, local project
assets, global sparks, optional version and project-rule management, runtime
repair, and explicit complex execution coordination.

It does not automatically scan projects, start workflows, split tasks, or
perform high-risk actions. Use KS only when it is relevant to the requested
work and confirm migration, publication, deletion, and other irreversible
operations.

## Included Skills

- `ks`: explicit KS entry and lightweight capability routing.
- `project-distribution-manager`: projects, planned external Git adoption, worksites, semantic project discovery, `ks-context`, and sparks.
- `version-manager`: optional project version management.
- `project-rule-manager`: user-confirmed long-term project rules.
- `execution-coordination`: explicit complex collaboration and recoverable chat-room state.
- `runtime-helper`: KS CLI runtime version checks and repair.

The source repository is the authoritative location for product architecture,
roadmap, and development documentation.
